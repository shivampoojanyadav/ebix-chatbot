# 🤖 Ebix AI FAQ Chatbot

An AI-powered FAQ chatbot built using Django, JavaScript, and Sentence Transformers.  
The chatbot understands user questions semantically and provides relevant answers instantly.

---

# 🚀 Features

- AI-based semantic search
- Dynamic chatbot interface
- Real-time responses
- Django backend integration
- FAQ database management
- Responsive UI
- NLP-powered similarity matching
- Admin panel support

---

# 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Sentence Transformers
- Scikit-learn
